# 文献到电场模型的映射与适用边界

本项目模拟半径 50 μm 的静态自由水滴、外部真空和 1–10 MeV 电子。数值出处、PDF 页码、液滴/界面尺度及介质列在[参数来源表](../data/literature_parameters.csv)。重复下载的两组 Nature Communications PDF 各只记录一个来源。本文不把纳米液滴、水–油界面或基底上液滴测得的局域场，直接等同于这个自由水滴在真空中的外场。

## 计算方程

对总自由电荷 $Q$，球外解析场为 $E_r=Q/(4\pi\epsilon_0r^2)$、$\phi=Q/(4\pi\epsilon_0r)$。所以球对称均匀表面电荷与给定的均匀体电荷在外部完全简并；内部前者电场为零，后者按 $r$ 增长。介电边界用 $\epsilon_\mathrm{out}E_\mathrm{out}-\epsilon_\mathrm{in}E_\mathrm{in}=\sigma_\mathrm{free}$ 检验。体电荷是受控比较情景，不宣称为平衡态。

中性同心双层由 $r_1=R-d$ 上的 $+Q_d$ 与 $R$ 上的 $-Q_d$ 构成；两个面上的密度大小分别是 $|Q_d|/(4\pi r_1^2)$ 与 $|Q_d|/(4\pi R^2)$，一般不相等。两壳外 $E=0$ 且 $\phi=0$，壳间可有强场。等效取向偶极层也用两壳表示：给定厚度 $d$、有效层介电常数 $\epsilon_d$ 和势差 $\Delta\phi$，反算 $Q_d=\Delta\phi\,\epsilon_d/[k(1/r_1-1/R)]$，其中 $k=1/(4\pi\epsilon_0)$。这只是连续介质平均极化层；纳米以下局域场不能由其推断。

PB 模型解球对称 Poisson 方程与 Boltzmann 离子分布，并通过积分约束固定每一种离子的总数。其输入必须满足 `q_e = surface_fixed_e + ion_positive_count - ion_negative_count`。PB 和另一个会促使离子重排的偶极/非对称电荷层目前禁止直接叠加，因为必须重新自洽求解；这在代码中触发错误，而不是静默重复计入屏蔽。固定分布模型之间可以线性叠加净电荷、中性层和冻结的非对称表面电荷。

表面非对称部分采用零单极矩的球谐展开，含 (l=1) 偶极、(l=2) 四极和有限宽度斑块。输出 `multipole_truncation_relative_rms` 比较当前阶数与更高阶场；值大时需加阶并重算。它表示冻结的自由电荷，不代表导电球的自洽静电平衡。

## 成像能与不能识别什么

电子轨迹由 Geant4 全路径电场和水材料输运给出；源的四维协方差决定束腰与发射度，探测器期望图与一次含噪曝光分开。外部轨迹只能识别外部场的投影效应；单投影一般不能唯一恢复三维电荷。穿滴电子可对不同内部场敏感，但水中的多重散射和能损会削弱该信息。中性双层零外场并不保证穿透图像完全相同。未看到可分辨的外部场，也不能排除强分子尺度界面场。

`Q=10^7 e`、`R=50 μm`、水表面张力 72 mN/m 时，$Q/Q_R\approx0.226$、$\phi(R)\approx288$ V、$E(R)\approx5.76$ MV/m；这些是模型值而不是文献测得的该液滴电荷。反应加速的因果机制不能仅由 shadow 图像判定。
